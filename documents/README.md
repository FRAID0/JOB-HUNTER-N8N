# Dossier des Documents de Candidature (Bewerbungsunterlagen)

Place ici tes documents au format PDF pour que le robot Playwright puisse les téléverser automatiquement dans les formulaires d'embauche :

| Fichier attendu | Description | Nom de fichier recommandé |
| :--- | :--- | :--- |
| **CV à jour** | Ton Lebenslauf complet | `cv.pdf` |
| **Relevé de notes** | Notenspiegel officiel (Hochschule Worms) | `notenspiegel.pdf` |
| **Certificat de scolarité** | Immatrikulationsbescheinigung (semestre en cours) | `immatrikulationsbescheinigung.pdf` |
| **Attestation de stage** | Praktikumszeugnis / Arbeitszeugnis de PWO AG | `praktikumszeugnis_pwo.pdf` |
| **Titre de séjour / Travail** | Aufenthaltstitel / Zusatzblatt (autorisation de travail étudiant) | `aufenthaltstitel.pdf` |

Le script `copilot_apply.py` ira chercher automatiquement ces fichiers lors du remplissage des formulaires en ligne.
